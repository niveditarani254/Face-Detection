# 😊 Face Detection using OpenCV & Streamlit

A simple and interactive **Face Detection Web Application** built using **Python**, **OpenCV**, and **Streamlit**. Users can upload an image, and the application automatically detects human faces by drawing bounding boxes around them using OpenCV's Haar Cascade Classifier.

## 📌 Features

* 📤 Upload images in JPG, JPEG, or PNG format
* 😊 Detect one or multiple faces automatically
* 🔲 Draw bounding boxes around detected faces
* 🖼️ Display both the original and processed image
* 📊 Show the total number of detected faces
* ⚡ Simple, lightweight, and easy-to-use interface


Move into the project folder:

```bash
cd FACE-DETECTION
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

---

## 📷 How It Works

1. Upload an image containing one or more faces.
2. The image is converted to grayscale.
3. OpenCV's Haar Cascade Classifier scans the image for faces.
4. Bounding boxes are drawn around each detected face.
5. The processed image and the total number of detected faces are displayed.
